# 🌍 TravelSphere

**Your Best Companion to Travel Around the World**

TravelSphere is a travel planning and booking platform designed to make trip planning simple, organized, and enjoyable. It allows travellers to discover destinations, explore travel packages, manage bookings, plan their travel budget, and keep track of their trips from one place.

The platform also provides an Admin Dashboard for managing travel packages and customer bookings.

## 💰 Budget Planner

TravelSphere includes a Budget Planner that helps travellers estimate and manage their trip expenses.

Users can plan expenses based on:

- Number of travel days
- Number of travellers
- Transportation type
- Hotel requirements
- Number of rooms
- Paid activities
- Approximate travel distance

The planner provides an estimated budget with expense categories such as:

- Accommodation
- Travel
- Dining
- Activities

## 👥 User Roles

TravelSphere supports two main roles:

**Traveller** – Searches destinations, explores packages, books trips, manages travel preferences, tracks trips, and plans travel expenses.

**Admin** – Manages travel packages, bookings, destinations, and platform information through the Admin Dashboard.

---

## 🎯 Project Objective

The objective of TravelSphere is to provide a single platform where travellers can easily discover destinations, plan their budget, explore travel packages, make bookings, and manage their trips while allowing administrators to efficiently manage packages and bookings.

---

## 🎨 UI/UX

The TravelSphere interface focuses on:

- Simple and clean navigation
- Travel-focused visual design
- Separate Admin and Traveller interfaces
- Easy package discovery
- Simple booking process
- Organized travel information
- User-friendly budget planning

The complete interface was designed and prototyped using **Figma**.
